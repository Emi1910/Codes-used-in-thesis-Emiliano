What each code:

- cfd_limite - Generates the laminar wall-normal flow.

- turb_cfd - Generates the turbulent wall-normal flow.

- cfd_1d_x - Generates the pressure and velocity of the flow along the duct. 

- Analise - Generates the histogram and calculates average velocity amplitude for a data frame.

- gerar_imagem - Generates the velocity field image for a certain freestream velocity of a dataframe

- separar_fases - Separates the boundary layers for each snapshot of a dataframe by freestream velocity and enables the generation of the "average boundary layer"

- scater - Generates the scater plot vxsnapshot for a dataframe
